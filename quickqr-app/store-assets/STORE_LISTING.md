## 스크린샷 가이드

Play Store에 최소 2장, 권장 8장의 스크린샷이 필요합니다.
크기: 1080 x 1920 (세로) 또는 1920 x 1080 (가로)

### 필요한 스크린샷 목록:
1. **QR 생성 메인 화면** - URL 입력 시 즉시 QR 미리보기
2. **WiFi QR 생성** - WiFi SSID/비밀번호 입력 화면
3. **QR 스캔 화면** - 카메라 뷰파인더
4. **스캔 결과** - URL 감지 결과 및 액션 버튼
5. **히스토리** - 생성/스캔 기록 목록
6. **커스텀 스타일** - 색상 변경된 QR 코드
7. **연락처 QR** - vCard 입력 화면
8. **설정** - 언어 변경 화면
